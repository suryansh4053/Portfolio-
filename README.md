# suryansh4053.github.io

Personal portfolio — live at **https://suryansh4053.github.io**

- Single-file site (`index.html`), no build step.
- LeetCode stats auto-sync every 6 hours via GitHub Actions (`.github/workflows/sync-leetcode.yml`) into `data/leetcode.json`.
- Interactive byte-visualiser renders any file as a grayscale image, entirely client-side.

Edit personal links/config in the `CONFIG` object at the top of the `<script>` in `index.html`.
